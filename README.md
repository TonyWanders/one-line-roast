A program that writes one roast of a gadget I use every day to `/output/entry.txt`, for the make.fun competition [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

## Run it

```sh
python3 main.py
```

It writes the roast below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The roast is 89 characters, inside the 1 to 200 gate.

> My Android dies at 4pm like it has a curfew, then begs for a charger like I owe it money.
